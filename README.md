# TechDesk

## Nome do Projeto
**TechDesk — Sistema Web de Gerenciamento de Chamados de TI**

## Descrição da Aplicação
O TechDesk é uma aplicação Web criada para centralizar, organizar e gerenciar solicitações de suporte e atendimento técnico de TI em pequenas e médias empresas.

## Problema que a Aplicação Resolve
Evita a perda de histórico, falhas de comunicação e desorganização decorrentes de chamados feitos por mensagens informais ou e-mails, disponibilizando um fluxo estruturado com controle de status, prioridades e canal direto entre funcionários e técnicos de TI.

## Tecnologias Utilizadas
- **Frontend:** HTML5 Semântico, CSS3, JavaScript, React.js
- **Backend:** Node.js, Express.js
- **Banco de Dados:** MySQL
- **Controle de Versão:** Git / GitHub

## Instruções para Execução
Atualmente, o projeto conta com as interfaces estruturais estáticas desenvolvidas em HTML5. Para visualizar as páginas:
1. Clone ou baixe o repositório em sua máquina.
2. Navegue até a pasta do projeto e abra qualquer um dos arquivos `.html` (ex: `index.html` ou `dashboard.html`) diretamente em seu navegador web.

Instructions completas de execução e build do backend/frontend em React serão incluídas nas próximas etapas.

## Funcionalidades Implementadas
- **Etapa 01:** Especificação inicial, escopo e proposta do projeto (`docs/proposta.md`).
- **Etapa 02:** Protótipo estrutural com HTML5 semântico contendo 4 interfaces principais:
  - `index.html`: Tela de login e autenticação.
  - `dashboard.html`: Painel geral e listagem de chamados unificada com controles de filtro.
  - `novo-chamado.html`: Formulário de abertura e registro de incidentes.
  - `detalhes-chamado.html`: Visualização e histórico de atendimento com área de comentários do técnico.
  - Documentação das decisões de marcação e acessibilidade em `docs/documentacao_etapa-02.md`.

## Limitações Conhecidas
- Esta entrega refere-se à **Etapa 02 (Protótipo Estrutural com HTML Semântico)**.
- As interfaces ainda não possuem estilização visual completa (CSS) ou dinamismo de interações via JavaScript.
- Não há integração funcional com servidor backend ou banco de dados nesta fase.
